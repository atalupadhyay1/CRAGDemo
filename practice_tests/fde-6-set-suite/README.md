# Forward Deployed Engineer (FDE) — Six-Set Practice Suite

This is an original, expanded practice suite built from the **public topic outline** of the [Udemy Forward Deployed Engineer (FDE) Practice Suite](https://www.udemy.com/course/forward-deployed-engineer-fde-practice-suite/). The public listing describes five 60-question tests covering data integration/ETL, system architecture/distributed systems, API design/integration patterns, production diagnostics/debugging, and client scenarios/interview simulation. This repository expands those public topic areas into **six original sets of 100 questions each**; Set 6 is a mixed capstone.

The Udemy course page was used only for its public description and topic list. These questions, options, explanations, and scenarios are original study material; they do not reproduce the paid course's questions, assignments, or lesson content. The suite is unofficial, is not endorsed by Udemy or the instructor, and cannot predict an employer's interview or hiring decision.

## Format

- Six separate sets; **100 single-best-answer questions per set**.
- Four choices per question.
- Suggested time: 150 minutes per set; 1 point per question; raw percentage = correct answers / 100 × 100.
- Each test and answer key are separate so the test can be taken without spoilers.
- No official pass mark. Use missed topics to guide further study.
